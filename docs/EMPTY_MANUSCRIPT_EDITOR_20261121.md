# 无成稿书籍完整编辑器修复

共享 `lib/` 和后端修复同时适用于 iOS/Android，实际 iOS 检出目录同步，保留账号、会员和首屏优化工作。

## 行为

点击无成稿书籍进入原有完整章节编辑器，不再只有空状态提示。可以直接添加正文，使用章节选择、重命名/新增、AI 文字/语音以及各平台已支持的工具。

编辑目录接口为无章节访谈书原子创建一个空白工作稿，重复打开不会重复创建。空正文不作为完成章节或成书内容。访谈后来整理成稿时，仅复用没有编辑、重命名、图片、草稿或聊天记录的初始空白位置；已有手写内容保持独立。

没有数据库结构迁移。生产覆盖包保留原服务 topic_directory 优化，仅增加空白工作稿初始化及复用逻辑。保留旧版发布及数据备份，不修改原始录音或既有书稿。
