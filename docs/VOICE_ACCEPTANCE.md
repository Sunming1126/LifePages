# OneSay 语音交互修正与验收

聊天输入区默认显示「长按说话」。右侧键盘切换到文字输入和发送按钮，文字框上方的麦克风切回语音。聊天与我的共用液态玻璃导航。录音时，OneSay 的实时文字与声纹面板显示在长按按钮上方。

未发送的旧录音保留在本地待处理队列，支持分别重试、补写文字和移除本地草稿。新录音可以继续创建，不会覆盖旧录音。已提交到服务端的请求继续使用原编号重试，避免重复发送。

无设备组件验收使用实际 FreeChatPage、OneSayChatNavigation、HoldToTalkButton 和 OneSayVoiceDock，仅录音硬件、网络返回和测试数据被替换。覆盖旧失败草稿下长按仍有反馈、实时文字修订、松手提交文字与 WAV、上滑取消、系统手势取消、授权未返回就松手、拒绝授权后再录音恢复，以及语音与文字切换时的草稿和键盘布局。实际组件图保存在 artifacts/voice-recording-headless.png。此图是组件测试渲染，不是模拟器或真机截图。

另使用阿里云官方公开的 18.87 秒说话样本，从本机调用已部署的短时凭证接口并直连 Fun-ASR：录音结束前收到 23 次文字更新，首段文字约 1.24 秒，音频结束后最终结果约 0.32 秒。以上是单次网络样本测试，不代表设备麦克风识别或所有网络条件下的表现。临时测试账号和凭证已清理。

没有启动模拟器；尚未进行真实手机麦克风和手指的完整体验验收，不将本次结果表述为与 OneSay 已完全等同。

说话样本来源：阿里云官方公开 CosyVoice 示例音频（https://dashscope.oss-cn-beijing.aliyuncs.com/samples/audio/cosyvoice/cosyvoice-zeroshot-sample.wav），未使用个人录音。
