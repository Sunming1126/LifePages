# 章节导航、字数圆环与书架编辑入口

分支：`ios/interview-theme-v2`；基线 `origin/android` 的 `e9e3ffd`。共享 `lib/`、`test/` 与访谈状态后端同时面向 iOS/安卓；实际 iOS 目录 `/Users/zhaoqing/myprojects/LifePages` 已同步，保留其首屏预加载、登录与会员未提交工作。

## 行为

- 点击书架封面/卡片始终进入章节编辑页，只有显式点击“继续访谈”才打开聊天。无已保存章节的访谈书也进入编辑页，显示待整理的空状态，不报加载失败、不生成虚构章节。
- 访谈左上角 48×48 方形“下一章节”，右侧为可点击的进度圆环。删除原顶部“跳过这题”“下一题”和常驻字数文字，保留最新未回答 AI 气泡的刷新。
- 点击圆环显示准确有效素材字数及成章要求；后台 `can_advance` 同时考虑 301 字和充分质量。仅字数达标的圆环最多显示 95%，充分后才满环。
- 用户确认保持“素材达标且故事收束后自动进入下一章”。左上角按钮是提前跳过；未达标时先确认，原话保留且主题标为 pending，不作为达标章节输出。
- 控制请求沿用带修订号和幂等请求号的 `interview_action=next`，显示/提交文本为“下一章节”。后端把该控制语解释为切换隐藏主题，区别于气泡刷新换同主题问题；控制文字不计入素材。
