# ChatChat 聊一聊样式移植

聊天气泡、输入框和思考动画的源实现来自本机 ChatChat 的 `lib/features/assistant/assistant_screen.dart`，移植为 `lib/chatchat_style.dart`。

- 气泡沿用原来的宽度比例、非对称圆角、边框、阴影、19px 正文及 AI 标识。用户消息不显示额外姓名标签；原声可通过长按消息访问。
- 思考动画沿用原来 1200ms 周期的三点颜色与缩放变化、左对齐及减少动态效果设置；只在等待模型回复时出现，完成或失败后移除。
- 页面使用 ChatChat 默认渐变与主题色，标题栏居中，文字模式沿用原始输入框和发送按钮，默认语音模式使用输入区内的「长按说话」。左上角会话入口沿用 ChatChat 设置面板的底部玻璃弹窗样式，支持新建、切换、重命名和处理当前会话的失败输入；右侧设置入口可编辑讲述者资料。
- 聊天列表只显示真实文字消息及回复状态；未知转写的旧录音不生成“语音已保存”等伪消息。失败录音仍在本地，位于记录入口的“未完成的输入”中。

验收使用实际页面组件，覆盖用户气泡、AI 气泡、等待回复的动画变化、返回后动画消失、录音输入与失败草稿保留。样式图在 `artifacts/chatchat-thinking-headless.png`，为无设备组件渲染，不是模拟器或真机截图。未启动模拟器。

底部导航和输入区按 ChatChat 的尺寸独立悬浮。语音模式文字直接位于输入岛内；文字模式的圆形麦克风浮在发送按钮上方。组件渲染图见 `artifacts/chat-voice-islands-headless.png` 和 `artifacts/chat-text-islands-headless.png`。

升级后已有消息自动显示在「原有对话」。新对话从独立上下文开始，相关旧记忆仍可由账号记忆簿检索。部署顺序为先更新后端，再更新 App。

应用内会话、资料、原声、讲述者选择和确认操作共用 ChatChat 底部玻璃弹窗，打开时覆盖底部导航；有文本输入时上移避开键盘。
